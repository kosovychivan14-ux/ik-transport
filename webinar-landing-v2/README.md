# Webinar Landing v2 — «Neon Evo» редизайн

Окремий незалежний проєкт (папка `webinar-landing-v2/`). Оригінал `webinar-landing/` НЕ змінено.

## Що нового в дизайні
- Сегментований неоновий таймер: великі скляні digit-бокси з лаймовою підсвіткою (hero + фінальний блок)
- Скляні HUD-картки з кутовими скобами: болі, вигоди (checklist), кроки
- HUD-індекси секцій: `[ 01 ]` … `[ 07 ]` у кікерах, моноширинний шрифт
- Сітка-підлога в hero (перспектива), сильніше неонове світіння, глибший чорний `#04060a`
- Той самий контент, та сама структура, ті самі JS-хуки — тільки візуальна система

## Структура
- `index.html` — розмітка (hero → болі → вигоди → програма → спікер → кроки → FAQ → фінальний CTA)
- `styles.css` — «Neon Evo» поверх «Neon Grid»
- `script.js` — той самий: таймер, reveal-анімації, лічильники, паралакс, sticky-CTA
- `assets/`, `og-preview.jpg` — скопійовано з v1

## Налаштування вебінару
Два рядки на початку `script.js` (як у v1):

```js
const WEBINAR_WEEKDAY = 4; // четвер (0=неділя … 6=субота)
const WEBINAR_HOUR = 19;   // 19:00 за Києвом
```
