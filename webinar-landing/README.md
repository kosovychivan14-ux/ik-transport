# Webinar Landing — конверсійний лендинг вебінару

Окрема версія лендингу, затежена під реєстрацію на безкоштовний вебінар.
Оригінали (`dist/`, `landing-v2/`) не змінено.

## Структура
- `index.html` — розмітка (hero → болі → вигоди → програма → спікер → кроки → FAQ → фінальний CTA)
- `styles.css` — дизайн-система «Neon Grid» (темна тема, лаймовий акцент `#d7f924`)
- `script.js` — таймер, reveal-анімації, лічильники, паралакс, sticky-CTA
- `assets/` — фото (скопійовано з `landing-v2/assets/`)

## Налаштування вебінару
Дата й час вебінару задаються **двома рядками** на початку `script.js`:

```js
const WEBINAR_WEEKDAY = 4; // четвер (0=неділя … 6=субота)
const WEBINAR_HOUR = 19;   // 19:00 за Києвом
```

Скрипт сам знаходить **найближчу** таку дату в майбутньому й підставляє її
в усі таймери та підписи («До початку вебінару», фінальний блок, мобільна панель).
Якщо дата минула — автоматично перекочується на наступний тиждень.

## Реєстрація
Усі CTA-кнопки ведуть у Telegram-бот: `https://t.me/ivankosovych_bot`

## Чесність даних
- Таймер — реальний, обчислюється від налаштованої дати (не фейковий).
- Без вигаданих лічильників місць і фейкових відгуків.
- У футері — дисклеймер, що матеріали не є фінансовою рекомендацією.
