# Вебінар-міні — «Інструменти доходу різного рівня ризику»

Міні-сайт під навчально-ознайомчий вебінар Івана Косовича.
Зміст — 1:1 зі сторінки https://ik-transport.vercel.app/webinar/ (жодних вигаданих цифр, кейсів чи відгуків).

## Що всередині

- `index.html` — один self-contained файл: шапка, hero, 5 смислових секцій
  (01 Чому це важливо · 02 Програма · 03 Спікер · 04 Доступ · 05 FAQ),
  фінальний CTA, футер з бренд-блоком.
- `assets/hero-portrait.png` — редакційний портрет Івана для hero (4:5, 1408×1760,
  згенеровано внутрішнім media pipeline 2026-09-24; очі природні, без неону).
- `assets/speaker-study.png` — Іван у теплій домашній бібліотеці для секції
  «Спікер» (16:9, 2048×1152, згенеровано внутрішнім media pipeline 2026-09-24).
- `assets/portrait.webp` — реальне фото Івана (більше не використовується на сторінці,
  лишено як резерв).
- `assets/og-preview.png` — OG-превʼю 1200×630 (згенеровано локально через PIL).

## Дизайн-концепт

«Тепла редакційна сторінка» — свідомо на 100% інша за поточний неоновий
лендинг (#06080c/#d7f924): кремовий папір `#f6f1e7`, чорнильний `#26231c`,
теракотовий акцент `#b4502a`, оливковий `#6c7048`; serif-антиква Fraunces +
Manrope; журнальна нумерація розділів, аркові рамки фото. Настрій —
спокійний, чесний, «паперовий», під тон вебінару.

## Як відкрити

Будь-який статичний сервер з кореня папки, наприклад:

```bash
cd ~/workspace/sites/_ivan/webinar-mini
python3 -m http.server 8931
# відкрити http://127.0.0.1:8931/index.html
```

Або просто відкрити `index.html` у браузері (шрифти Google Fonts підтягнуться
з мережі; без неї — системні запасні).
