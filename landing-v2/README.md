# landing-v2 — новий дизайн лендінгу IK

Незалежна концепція редизайну, **не чіпає** поточний сайт у `dist/`.

## Концепція: «Neon Grid»

Натхнення — тренди лендінгів 2025–2026 (Pinterest / Dribbble / Behance):
- темна преміальна тема, глибокий чорно-синій замість чистого чорного;
- гігантська типографіка як головний візуальний елемент (solid + outline + акцент);
- електричний лайм `#d7f924` + ціанові відблиски, неонові орбітальні градієнти;
- сітка-фон, marquee-стрічка, bento-картки, скляні «чипи» поверх фото;
- мікроанімації: reveal при скролі, float-чипи, hover-підйом карток.

## Шрифти

- **Unbounded** — дисплейний (кирилиця ✓)
- **Manrope** — текстовий (кирилиця ✓)

## Структура

- `index.html` — розмітка (українською)
- `styles.css` — весь дизайн, responsive + reduced-motion
- `script.js` — навігація, reveal-анімації, FAQ-акордеон
- `assets/` — зображення (копії з `dist/`, оригінали не змінено)
