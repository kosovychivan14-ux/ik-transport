# Вебінарна кімната: обов’язковий зв’язок із лендінгом

Цей лендінг є початковою точкою шляху до вебінарної кімнати. Вебінарна платформа не замінює лендінг і не має бути першою адресою для реклами.

```
Лендінг IK Transport
        ↓ «Отримати доступ»
Telegram-бот @ivankosovych_bot
        ↓ вітальна воронка SendPulse
Нагадування та фінальне повідомлення
        ↓ кнопка Web App / Mini App
Вебінарна кімната
https://ik-webinar-telegram-test.vercel.app/live.html#room
```

## Що вже з’єднано

- Усі кнопки доступу на цьому лендінгу ведуть до `@ivankosovych_bot`.
- Бот запускає вітальну воронку SendPulse.
- Фінальні повідомлення воронки відкривають вебінарну кімнату за URL вище.
- Завершення прогріву SendPulse надсилає захищену подію у вебінарну кімнату, щоб надати доступ до персональної прем’єри.

## Правило для змін

Якщо змінюється адреса кімнати або Telegram-бот, треба оновити одночасно:

1. кнопки цього лендінгу;
2. кнопки у фінальних повідомленнях SendPulse;
3. налаштування доступу та webhook вебінарної кімнати.

Не зберігайте у Git webhook-секрети, токени або ключі.

## Стан GitHub

Цей лендінг зберігається у GitHub-репозиторії `kosovychivan14-ux/ik-transport`. Код вебінарної кімнати тепер є його частиною у папці `webinar-room/`; окремого вкладеного Git-репозиторію більше немає. Після наступного безпечного коміту й push ця сама структура з’явиться на GitHub.
